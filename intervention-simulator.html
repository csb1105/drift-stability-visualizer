Model basis and validation record
ISS v1.0 baseline validation date: 2026-06-10
Validated features: ISS scoring, driver dominance detection, velocity metric, acceleration metric, coupling detection, intervention recommendation engine.
Controlled validation cases: Stable, Pressure Driven, Divergence Driven, Alignment Collapse, Coupled Failure. All recorded PASS.

Core relationships:
A_eff = alignment × resilience
C = resilience + margin
D = pressure + divergence + (1 − A_eff)
I = pressure(1 − resilience) + divergence(1 − A_eff) + pressure×divergence
S = C − D − I
ISS = 1 / (1 + exp(−4S))
